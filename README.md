# Full-Stack Task Management Application

A modern full-stack task management application built with React, Material UI, Golang, PostgreSQL, and Docker Compose.

This project demonstrates full-stack development concepts including frontend/backend architecture, REST APIs, database integration, containerization, and responsive UI development.

---

## Tech Stack

### Frontend

* React
* Material UI
* Vite
* JavaScript
* CSS

### Backend

* Golang (Gin)
* REST APIs

### Database

* PostgreSQL

### DevOps / Infrastructure

* Docker
* Docker Compose

---

## Features

* Create tasks
* Update tasks
* Delete tasks
* Mark tasks as completed
* Responsive modern UI
* Backend API integration
* PostgreSQL data persistence
* Containerized full-stack environment

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Massoumeh-Mahaei/todo-golang.git
cd todo-golang
```

---

## Run with Docker Compose

```bash
docker-compose up --build
```

Frontend:

```bash
http://localhost:5173
```

Backend API:

```bash
http://localhost:8080
```
